# 维护者发行检查清单

这是一份可复用清单，不表示某个构建已完成以下测试。V0.2.6-GA 原发行的人工验收由用户确认；具体自动化结果仍以对应历史报告为准。每次修改运行布局和打包规则后，需要对新包单独验证。

- 核对提交、源码指纹、应用/QML/便携入口身份、附件摘要与包内清单；源码包含全部实际改编和构建材料。
- 在隔离资料目录与无开发环境 PATH 下验证便携启动、QML 插件、ffmpeg/ffprobe、封面和媒体导入。确认共享库路径及不同版本的 FFmpeg 均正确解析。
- 验证五个平台的登录、恢复、退出、推荐缓存和账号歌单。真实账号、会员权限、付费服务和听感由用户本人检查，不收集凭据或个人数据库。
- 验证本地与在线视频、只音频、拖动、分 P、质量切换、切歌和混合队列；特别检查展开/收起、迷你和后台恢复的声音连续性。
- 验证输出设备切换、歌词、MIDI、试听片段及现有下载功能。未实现功能不记作通过。
- 验证宽窄布局、字体/DPI、侧栏整体滚动、列表记忆、历史、设置与退出保存。
- 保留原始结果，区分产品缺陷、测试预期维护、阻塞和未执行项；不将历史结果改写为新一轮全绿。
- 检查发布包未携带个人 data、测试截图/日志、编译缓存或开发机路径。许可、版权、改编说明和对应源码获取方式仍完整。

检查时使用独立资料副本。用户正常运行目录不作为开发或 Harness 测试输入。发现问题记录版本、操作、实际结果和可复现性；截图与日志先脱敏。
