# Relaxer V0.2.6-GA-r2

2026-11-21

本修订版集中修复播放、封面和窗口布局问题。程序内版本仍显示 V0.2.6-GA，发行标签和附件使用 r2 区分；原 V0.2.6-GA 保留。

- 修复窗口隐藏后在 D3D11 下恢复时封面空白，保留已显示封面、遮罩和背景；普通列表离开页面仍可释放图像。
- 修复封面异步回调生命周期、混合队列稳定性、播放状态保存与恢复，以及多平台列表与封面缓存问题。
- 修复最大化快捷收窄的右边界跳动、底栏标题提前省略；完善窄窗、历史列表和视频封面布局。
- 展开视频的中央加载大封面使用直角，音频模式及其他小封面保留圆角。
- 保留音频源与播放状态，完善分 P 快速切换、每 P 进度和异步缓存持久化的回归验证。

## 下载与升级

下载 `Relaxer-V0.2.6-GA-r2-Win64.zip`，完整解压到新的可写目录，双击根目录 `Relaxer.exe`。兼容界面使用 `Relaxer.exe --widgets`。升级前退出旧版并备份整个 `data/`，先用资料副本验证，不混装运行库，不让两个版本同时写同一资料目录。

## 验证范围

Round5 经独立重新构建并完整执行 97 项 CTest：原始结果为 96 套件通过、1 套件因测试环境的临时目录清理异常失败；该套件同环境随后 6/6 复跑通过。QtTest 用例级 1898 通过、0 失败、26 跳过，0 次异常退出。隐藏/最小化封面在 software 与硬件 D3D11 两个后端独立通过。本结论不是一次完整 97/97 全绿，详见同目录 VALIDATION.md。

真实账号、会员音质、PCM 听感、GPU 高斯模糊、失焦/托盘、多显示器、真实音频/MIDI 设备及 30 分钟长稳未在该轮完整验证，不计为通过。
