# Relaxer V0.2.7-RC

2026-11-26，Windows x64 候选预发行版。

- 全覆盖参数均衡器，支持歌曲、来源歌单、平台及全局适配；歌曲适配优先。
- 实时试听、手动保存，离开时保护未保存的均衡器调整。
- MIDI 自定义 SF2/SF3 音色库管理及合成设置，下次启动生效；默认保留 GeneralUser GS，继续使用 FluidSynth。
- 自建歌单可混合本地及在线音乐和视频。「我喜欢」显示曲目来源，红心可按资料库、我的歌单、发现页分别启用。
- 优化下一首列表的编辑、多选、右键操作、定位及窄窗布局。清空时暂停当前曲目并保留播放位置。
- 优化设置页宽窄切换、底栏及迷你播放器的布局。
- 在线歌曲和视频封面成功加载后写入磁盘，供下次启动复用。修复版本日志展开时页面向上跳动，并整理早期版本记录。

下载 `Relaxer-V0.2.7-RC-Win64.zip`，完整解压后运行根目录的 `Relaxer.exe`。升级前请退出旧版本并备份资料。使用独立目录可以同时保留现有安装与资料。

Round39 独立回归首轮 97/97 套件通过，无失败、超时或崩溃。QtTest 记录 1907 项通过、26 项跳过。详见 `VALIDATION.md`。

应用按 GNU GPL v3 发布。对应应用源码、MIDI、修改版 FFmpeg 和 Qt 多媒体处理模块源码随发行提供；基础运行库对应源码沿用 [V0.2.2-GA 第三方源码附件](https://github.com/QUEQIAN1961/Relaxer/releases/download/v0.2.2-GA/Relaxer-V0.2.2-GA-Third-Party-Source.zip)。
