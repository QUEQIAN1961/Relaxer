# Relaxer V0.2.0 升级指南

V0.2.0 沿用 RC2 的 data 根目录身份、relaxer.sqlite 和数据库 schema。正式版不会因版本号变化新建空库、重新分类或自动调用 DeepSeek。

1. 完全退出旧版播放器与托盘实例。
2. 备份旧目录整个 data，保留只读备份。
3. 将正式便携 ZIP 完整解压到一个新目录，不覆盖 RC1、RC2 或已有安装。
4. 将旧 data 的副本复制到新目录，与根目录 RelaxerStart.exe 同级；保留 Music、歌词、图片及数据库的相对位置。
5. 启动新目录的 RelaxerStart.exe，检查歌曲、歌单、收藏、统计、歌词、人工分类、外观、音量与队列。
6. 正常关闭后再次打开，确认内容保留。确认成功后仍建议保留旧包和 data 备份。

不要在旧版仍运行时复制 SQLite 文件，不要让两版同时写同一 data。不要只复制歌曲而丢下数据库，或只复制数据库而丢下管理目录。

若升级失败，完全退出新程序，保留故障副本及日志，然后将备份 data 复制到另一目录并用原版本打开。人工分类自 RC2 引入，旧版未必显示，但未知设置键会按既有机制保留。

自动兼容验证使用合成 RC2 数据副本，不操作用户正式曲库。用户已报告 RC2 的真实旧库副本升级 PASS；这不是正式版重新操作用户真实数据库的声明。
