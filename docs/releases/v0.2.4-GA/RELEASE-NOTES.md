# Relaxer V0.2.4-GA

本版整合自适应窄窗、单窗口迷你播放器、双语歌词和界面交互改进。

本次修订使用标签 `v0.2.4-GA-r2`，应用版本仍为 V0.2.4-GA；原始 `v0.2.4-GA` 标签与发行包保留。修正窄窗关闭歌词查找时的布局重入警告，同步自适应、队列和延迟加载的回归断言，并改为连续观察下拉动画的高度变化。

## 更新内容

- 新增自适应窄列表，调整导航、搜索、播放栏及队列在窄窗中的显示。
- 迷你播放器复用同一窗口，支持应用内 `Ctrl+Shift+M` 和受全局快捷键开关控制的 `Ctrl+Alt+M`，均可自定义。迷你模式置顶，退出恢复原窗口及置顶规则。
- 支持四角及相关边缘连续拖拽切换、阻尼拉伸和松手回弹，改进固定对角、DPI 取整与模式过渡动画。
- 迷你播放时保持封面，右侧显示当前原文及可用译文；无译文时单行居中。长句按剩余句长从右向左展示，句尾停留后换句。暂停或没有可同步歌词时显示歌曲信息，悬停可使用播放控制。
- 优化歌单排序、歌单标记、搜索、字体、歌词颜色、编辑菜单、对话框与弹出面板，保留播放、队列及未保存草稿。
- 歌词查找页进入窄列表时停止相关查找、翻译等任务并返回本地音乐。
- 隐藏或最小化时释放可重建的图像、玻璃效果和临时弹出窗口资源，播放及状态继续保留。

## 下载与升级

Windows x64 包：`Relaxer-V0.2.4-GA-Win64.zip`。完整解压至新的可写目录，双击根目录 `Relaxer.exe`；兼容界面使用 `Relaxer.exe --widgets`。运行包自带依赖，不需要安装 Qt 或编译工具，不要单独取出 EXE 或混装 runtime。

升级前完全退出旧程序并备份整个 `data/`，先用资料副本验证。默认资料位于包根目录 `data/`，也可用 `--data "绝对资料目录"` 指定；不自动迁移、合并或清理用户资料，不能让两个实例同时写入同一份资料。

## 验证与发布

发布条件为针对同一源码提交和同一组附件完成一次独立全量回归，P0/P1/P2 问题为零，必测项有实际证据。组包时的 `BUILD-IDENTITY.json` 记录构建身份及当时待验收状态；它不替代同批 Harness 报告，也不代表已公开上传。公开状态以 GitHub 实际 Release 为准。

开发阶段的针对性验证覆盖迷你歌词、播放与草稿保持、窗口缩放、DPI、原生鼠标输入及后台资源生命周期。既有自测通过不代表全量回归已完成，也不保证所有机器上的动画手感、跨屏行为或真实听感。离线 Mock 验证不代表在线服务持续可用。
