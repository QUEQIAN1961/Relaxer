# RC2 已知限制与人工验收

当前是候选版本，须经过 Harness R10 及用户真实 Windows 测试后，才决定是否正式发布。没有创建正式 v0.2.0 标签。

MIDI 文件打开成功、系统报告 Playing、进度推进与物理出声是不同证据。自动化可验证前两者及传输控制；物理听音和真实 MIDI 硬件输出仍需人工确认。系统没有 MIDI 输出设备或后端拒绝命令时会显示错误，不能据此报告成功。没有引入大型替代合成器。

请在新便携目录用副本执行：

1. 导入报错 MIDI，播放、暂停、恢复、拖动进度，确认实际有声且暂停无声。
2. 连续切换两首 MIDI，再切换 WAV/MP3，并从普通音频切回 MIDI。
3. 选择顺序播放，跳到最后数秒，确认结束行为、统计与重启恢复。
4. 重复开关播放器，确认 MIDI 设备释放；必要时查看 `data/logs/midi.jsonl`。
5. 在缺失翻译模式逐一切换、撤销两个分类按钮，重启确认分类保留。
6. 完成歌曲会离开缺失列表；取消筛选可在全部歌曲中找到并撤销人工判断。
7. AI 译文仅在保存成功后成为翻译完成；关闭、切歌、改变分类或放弃预览时先确认，取消应继续可保存。
8. 真实付费翻译只在用户自行配置凭据并明确授权计费后进行；本轮全部使用回环 Mock，真实付费请求为零。

继承的非阻断问题见开发报告问题登记表。D-R8-02（退出最终保存失败后不能重试）继续保持既有退出交互，本轮没有获得改变该交互的追加授权。D-R8-03、D-R7-02 等无关历史问题没有顺手改造。

真实外部歌词站点、真实 DeepSeek、Linux、突然断电、一小时以上稳定性及 sanitizers 未执行。临时副本正常关闭会清理；突然终止进程时的临时文件清理不等于已验证的断电恢复。
