# Relaxer V0.2.3-GA

本版整合 Phase E 的界面、交互、启动与后台资源优化，并更新 MIDI 播放后端。

## 更新内容

- 统一圆角对话框、勾选按钮与播放图标，优化歌曲列表、设置、个人页面和歌词工作区的间距与对齐。
- 完善页面、歌词查找、多选、下拉列表及通知的进入和退出动画；下拉列表保持宽度、按高度展开。
- 修复歌词跳转进度、歌词正文误触、退出查找后歌曲数量异常、展开播放时标题短暂省略和外观返回动画重复等问题。
- 导入音乐显示数量进度；歌曲列表悬停播放按钮保持稳定，不再反复闪烁。
- 新增 KIMI 与 Qwen API 配置，完善 KIMI 请求协议、模型名称、实际生效配置提示、Qwen 模型精选与支持模型的思考强度选项。
- 减少启动时无关的音视频硬件探测，缓存界面设置与外观计算；设置、外观等页面首次进入时再创建。
- 隐藏或最小化时释放可重建的图像与渲染资源，保留播放、队列、快捷键及未保存外观草稿。
- MIDI 改用 BASS/BASSMIDI 与 GeneralUser GS 音色，改善密集音符播放，支持暂停、继续和进度跳转；切回普通音频后释放 MIDI 运行资源。
- 修复动画菜单尺寸循环，并修正回归测试对展开、关闭动画与截图合成精度的同步方式。

## 下载与升级

下载 `Relaxer-V0.2.3-GA-Win64.zip`，完整解压到新的可写目录，双击根目录 `Relaxer.exe`，无需安装 Qt 或开发环境。兼容界面使用 `Relaxer.exe --widgets`。不要在压缩包预览中运行，也不要单独取出 EXE 或混装 runtime。

升级前完全退出旧版并备份整个 `data` 目录，建议先使用资料副本。默认资料在包根目录 `data/`，也可使用 `--data "绝对资料目录"`。本版保留现有资料格式，不自动迁移、合并或清理用户资料；不要让多个实例同时写同一份资料。
