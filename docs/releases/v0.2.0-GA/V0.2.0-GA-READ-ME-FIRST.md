# Relaxer V0.2.0-GA — 先读说明

这是 Phase B Foundation 正式版。本地正式交付于 2026-10-18 完成；播放器在 2026-10-17 重新构建并通过自动回归，2026-10-18 用户报告本版 7 项人工检查全部通过。正式版沿用已通过 Harness R10 的 RC2 业务逻辑。

直接使用请选择 `Relaxer-V0.2.0-GA-Win64-Portable.zip`，完整解压到新目录，双击根目录 `RelaxerStart.exe`。便携包自带 Qt、MinGW 与 FFmpeg 运行依赖，不需要安装开发环境；本地播放可以离线使用。

升级前完全退出旧程序并备份整个 `data`，将副本放在新启动器旁。不要覆盖既有安装，不要让两版同时写同一份数据。资料目录与数据库 schema 不变，详见 `V0.2.0-GA-Upgrade-Guide.md`。

歌词可逐首标记“需要翻译”或“无需翻译”，再次点击撤销。AI 整首翻译只对符合条件的单曲开放，仍须逐次确认可能产生的费用。译文先预览，保存成功才显示完成；关闭、切歌和修改分类时保护未保存译文。

源码包与完整历史 bundle 用于开发和恢复；直接使用请选便携包。完整交付总包包含上述三项及发布文档、11 份报告和验证材料。请通过外部 `SHA256SUMS.txt` 检查实际文件，`DELIVERY.json` 提供冻结身份与校验范围。

RC2 的独立 Harness R10 技术验收 PASS；**USER-REPORTED MANUAL ACCEPTANCE — 6/6 PASS（RC2）**。本次正式版另有 **USER-REPORTED MANUAL ACCEPTANCE — 7/7 PASS（V0.2.0-GA）**，来自用户本轮确认，均不冒充 Codex 独立听音或付费请求。

当前继承 22 项非阻断 P3，P0/P1/P2 为 0；完整台账见 `V0.2.0-GA-Known-Issues.md`。MIDI 设备兼容性、在线站点和 AI 服务可用性仍取决于外部环境。

本次仅完成本地交付；没有公开上传、远程推送或覆盖原有安装。历史启动握手 `version=1.5.0` 保持原协议含义，产品正式版本为 0.2.0-GA。
