# 最终 GA 候选验收矩阵

先固定候选 ZIP、Commit、Tree、Fingerprint、源码/补丁/依赖/许可侧包摘要；每次身份或运行字节变化都更新清单，不能复用旧批准。以下为尚未执行的最终 GA 计划，本轮已执行项见证据报告。

| 范围 | 最终候选验收 | 判定要求 | 执行者 |
|---|---|---|---|
| 身份与恢复 | bundle 独立克隆、fsck、源码 ZIP 逐 blob、补丁从冻结父提交重放、全新构建 | Tree 与 Fingerprint 一致，核心同源，零混装 | Codex / Harness |
| 原冻结产品 | 全 CTest 93 项；逐条记录内部 SKIP；RC6 六项、日志合并、GA 历史、日期、重入折叠、歌词/播放/数据库 | 无确证回退；不得将 SKIP 算已覆盖 | Codex / Harness |
| Escape 与 Artwork | 保留已有失败与未解风险；如断言再失败收集原始状态，不假定焦点原因；按既有专项自然建轨 | 透明记录，不以未复现宣称修复 | Harness |
| 用户包结构 | 全新解压且仅根 EXE；无准备工具、ready、源码、测试资料或个人库；全部本机路径/凭据扫描 | 包结构符合报告 03，原始证据另存 | Codex / Harness |
| 首次及移动 | 新目录首次打开、第二次打开、中文/空格、整体移动、默认和外部资料目录、同库锁、正常退出保存、CMD 退出再 EXE | 真正首帧与交互；不止进程创建；资料与媒体保持 | Codex / Harness |
| 完整性 | 1,859 文件全 SHA / 4 线程无缓存；缺失、篡改、同长同 mtime、隔离、穿越、重复、reparse、错误源码指纹 | 先拒绝再建资料；错误反馈与恢复说明可理解 | Codex / Harness |
| 音频 | PCM 解码、实际声卡程序化测试与人工多格式听音、暂停/跳转/切歌/音量/统计 | 人工听音单列，不以静音 PCM 或进度替代 | Codex / 用户 |
| 人工输入 | 鼠标与键盘、Escape、歌词查找记录关闭/外点、全屏歌词返回、设置日志重入、窗口边界 | 真实前台事件，证据注明人工/SendInput/Qt 类型 | 用户 / Harness |
| DPI | 在真正 100% DPI 环境操作全部关键页 | 用户环境结果，不能改宿主 DPI 冒充 | 用户 |
| 在线服务 | LRCLIB 正常/无结果/失败及翻译授权账户场景 | 免费与收费分开；额度使用获用户授权 | 用户 / Harness |
| 许可与源码 | 每个实际 DLL/EXE→二进制包→源码/补丁/配方→最终锁/静态依赖/通知；真实 Qt ABI 替换；源码侧包独立恢复 | 报告 01 中 BLOCKED/OPEN 有证据关闭；同址源码提供可用 | Codex / 来源维护者 / Harness |
| GA 身份 | UI 标题、--version、User-Agent、Windows 版本资源、更新日志、BUILD/COMPONENTS/部署身份 | 全部最终身份一致；工程/内部提示不混入普通更新日志 | Codex / Harness |
| 公开发行 | 最终校验和、桌面副本、来源/版本说明、源码下载对应关系、人工门批准 | 另行用户放行；本轮没有授权公开发布动作 | 发行负责人 |

Qt 实际替换必须使用重新构建且 ABI 兼容的共享库，当前 PE overlay 试验只能证明启动机制允许拥有者修改清单。完整性清单是本地未签名基线，不能将它当作独立发行者签名。最终正式候选若改版本资源/部署文案，也必须按新 Fingerprint 复验。
