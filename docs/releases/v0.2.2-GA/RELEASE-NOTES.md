# Relaxer V0.2.2-GA

本版本汇总此前的播放、歌词、歌单与便携启动修复，保留 QML 主界面及 Widgets 兼容模式。

- 完整解压后，双击根目录 `Relaxer.exe` 即可启动，无需安装 Qt 或开发环境。
- 操作记录可关闭、点击外部收起并自动隐藏，减少界面遮挡。
- 歌词搜索停止后保留已经完成的结果；纯音乐统一显示“纯音乐，请欣赏”。
- 整理展开歌词页的按钮与版本日志显示，保留全屏歌词和 Escape 返回操作。
- 沿用现有播放、导入、歌单、队列、歌词和设置的数据格式。

下载 `Relaxer-V0.2.2-GA-Win64.zip` 并完整解压到新的可写目录，双击 `Relaxer.exe`。兼容界面可运行 `Relaxer.exe --widgets`。

升级前完全退出旧程序，备份整个 `data` 目录，用资料副本验证新版本。不要覆盖混装 `runtime`，不要让两个版本同时写同一资料目录。程序支持 `--data "绝对资料目录"`，不会自动迁移或清理旧资料。

Windows 包、源码及第三方来源材料以同一 Release 的附件和 `SHA256SUMS.txt` 为准。在线歌词需要网络；翻译提供方、凭据与付费请求由用户自行选择和确认。

本文件是待发布说明，当前没有创建 GitHub Release。二进制公开发布以最终发行条件检查和发行者确认结果为准。
