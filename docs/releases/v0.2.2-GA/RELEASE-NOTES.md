# Relaxer V0.2.2-GA

Relaxer 是 Windows 本地音乐播放器，支持音乐库、歌单、播放队列、滚动歌词和自定义外观，并保留 Widgets 兼容界面。

## 本版更新

- 汇总播放、歌词、歌单与便携启动的修复。
- 操作记录可以关闭，点击外部即可收起，并支持自动隐藏，减少界面遮挡。
- 歌词搜索停止后保留已经完成的结果；纯音乐统一显示“纯音乐，请欣赏”。
- 整理歌词展开页的按钮与版本日志显示，保留全屏歌词及 Escape 返回操作。
- 沿用现有曲库、歌单、队列、歌词和设置的数据格式。

## 下载与安装

下载 `Relaxer-V0.2.2-GA-Win64.zip`，完整解压到新的可写目录，双击根目录 `Relaxer.exe`，无需安装 Qt 或开发环境。不要在压缩包预览中运行，也不要单独取出 EXE。兼容界面可运行 `Relaxer.exe --widgets`。

升级前完全退出旧版并备份整个 `data` 目录，建议先用资料副本验证。不要混装不同版本的 `runtime`，不要让两个版本同时写入同一份资料。可用 `Relaxer.exe --data "绝对资料目录"` 指定资料位置；程序不会自动迁移、合并或清理旧资料。
