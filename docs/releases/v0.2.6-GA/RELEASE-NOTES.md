# Relaxer V0.2.6-GA

2026-11-15

新增汽水、酷狗和哔哩哔哩接入，支持账号登录、视频与用户搜索、收藏夹固定、自动分页和分P选择。加入本地视频、音乐视频混合队列、云端与本地视频只音频模式，以及本地视频歌词。新增播放历史、启动页面与播放进度记忆，完善字体、侧栏宽度、歌曲快捷按钮和会员标识设置。修复平台登录、歌单读取、封面清晰度、试听资源与播放失败重试；优化展开播放的音轨连续性、视频拖动、底栏和宽窄窗口布局。侧栏统一滚动，滚动条避让按钮，补齐初始定位。收紧前后台图片资源和多平台缓存，清理动画快照，少量动画同时关闭快捷键进入与退出迷你播放器的过渡。

下载 `Relaxer-V0.2.6-GA-Win64.zip`，完整解压到新的可写目录，双击根目录 `Relaxer.exe`。兼容界面使用 `--widgets`。升级前退出旧版并备份自己的 `data/`，保留完整运行库和校验清单。

应用代码采用 GNU GPL v3。应用对应源码见同版 `Source.zip`，MIDI 组件和修改版 FFmpeg 的对应源码、配置与补丁分别见 `MIDI-Source.zip`、`FFmpeg-Source.zip`；未修改的基础依赖沿用 [V0.2.2-GA 第三方源码附件](https://github.com/QUEQIAN1961/Relaxer/releases/download/v0.2.2-GA/Relaxer-V0.2.2-GA-Third-Party-Source.zip)。[引用与致谢](https://github.com/QUEQIAN1961/Relaxer/blob/v0.2.6-GA/REFERENCES.md)保留各项目作者、固定版本、实际使用范围及独立许可。
