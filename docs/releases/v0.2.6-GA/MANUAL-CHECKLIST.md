# V0.2.6-GA 人工检查清单

2026-11-15 用户确认已自行实测通过并授权发行。以下保留为后续版本可复用的人工检查清单，人工确认不等同于新增自动化测试结果。使用你自己的正常账号和设备，不需要把 Cookie、API Key、个人数据库或媒体文件交给开发/测试代理。首次使用升级版本前备份自己的资料，避免两个进程同时写同一份资料。

## 建议优先检查

- [ ] **五个平台的真实账号**：按自己实际使用的平台，登录、完全退出程序后重启，核对账号名、清晰头像、会员标识和登录恢复；退出账号后应回到未登录状态。
- [ ] **真实音乐播放**：网易云/QQ及自己使用的汽水/酷狗，选有权限的歌曲播放、暂停、拖动和切歌；检查普通/会员歌曲、音质选择、偶发播放失败后的重试与跳过。平台尚不支持的接口或加密资源单独记下。
- [ ] **B站收藏夹与搜索**：登录后默认进入自己的收藏夹，收藏夹内容/封面、搜索视频和用户、滚动继续加载、固定侧栏均符合实际账号；登录恢复期间切到搜索页，不应被收藏夹响应顶回去。
- [ ] **B站真实视频和分P**：选多P视频，切P、自然续P、最后P进入下一首；播放控制的下一首仍切队列项。播放中调整画质/音质，检查可用上限、会员权限及进度/暂停状态保持。
- [ ] **音轨连续性与同步听感**：播放真实在线视频，反复展开、收起、进入/退出迷你及最小化恢复；留意新增卡音、重复声音和音画漂移。视频显示后拖动，旧帧应保留至新位置就绪，不闪回封面；暂停拖动后应保持暂停。切P/画质/音质本身可能需要缓冲。
- [ ] **真实输出设备**：如有耳机、扬声器或蓝牙，右键音量图标切换设备，检查本地/在线音频和MIDI实际从正确设备发声；再检查播放/暂停时切换、拔插、跟随系统默认及重启记忆。观察程序没有改动Windows全局默认设备。

## 按实际使用补充

- [ ] **本地视频与歌词**：拿自己常用格式，分别检查视频/只音频、歌词开/关；音轨模式显示封面和歌词，视频模式歌词位于画面底端。检查无内嵌封面时的同名图/第一帧回退，以及字幕同步。
- [ ] **MIDI实际听音**：选自己熟悉的MIDI，检查音色、速度、音量、暂停/拖动/恢复及切换输出设备，确认无持续杂音或静音。
- [ ] **真实下载与NCM**：仅在自己有权限且使用该功能时，检查下载、取消、重复识别、默认目录与音质记忆；使用自己的授权NCM样本确认转换结果可播放。B站视频下载仍未开放。
- [ ] **AI与翻译**：仅在使用这些功能时，用自己的配置确认重启恢复、模型选择、一次真实翻译及取消；确认取消后的界面和已保存歌词符合预期。无需为清单专门开通付费服务。
- [ ] **日常资料与恢复**：用资料副本先检查旧歌单、收藏、歌词、排序、历史来源/时间及重启进度；再按自己的常用操作使用一段时间。
- [ ] **实际显示环境**：若有多屏/不同DPI，检查跨屏、快捷宽窄、迷你和最大化恢复的边界、焦点及按钮可达性；以常用D3D11后端为主，不必重复Harness全部尺寸矩阵。
