# Relaxer V0.2.3-RC

本候选版整合 V0.2.2-GA 之后的 Phase E UI 与交互调整。当前仅生成本地测试包，不代表 V0.2.3-GA 已发布，也尚未上传 GitHub。

## 更新内容

- 统一圆角对话框、按钮与图标，调整歌曲列表、个人页面、设置页面与底栏的间距。
- 放大歌曲列表播放图标，播放中使用双竖线；点击当前歌曲图标可暂停、继续并保留进度。
- 优化页面切换、查找歌词、多选、下拉列表和通知的动画。下拉列表保持宽度，以高度展开；通知按下缩放为 96%。
- 修复歌词左侧按钮无法跳转播放进度、正文误触跳转、退出查找歌词后歌曲数量异常和展开播放时标题短暂省略等问题。
- 整理歌词操作入口、列宽与批量操作布局，修复外观返回动画重复播放，增加音乐导入数量进度。
- 新增 KIMI 与 Qwen API 入口，支持 KIMI K3 请求协议，显示实际生效的翻译配置，统一模型名称。
- Qwen 从官方能力目录自动精选模型；Qwen3.8-Max、0902 快照和 Qwen3.8-Flash 支持 LOW / MEDIUM / XHIGH 思考强度。
- 修正多选与歌词替换测试中的旧断言、弹窗同步，验证冲突保护、保存落盘和保存后推进。

## 使用

完整解压 `Relaxer-V0.2.3-RC-Win64.zip` 到新的可写目录，双击根目录 `Relaxer.exe`。兼容界面使用 `Relaxer.exe --widgets`。

默认资料位于包根目录 `data/`。升级前完全退出旧程序并备份原资料，先用副本验证；不要混装不同版本的运行文件，也不要让两个版本同时写入同一份资料。本版未更改现有资料格式。

## 验证范围与已知事项

- 之前的离线全量回归覆盖主要功能；本轮另验证版本资源、更新日志、相关 UI 用例与实际打包后的启动。
- BUG-01 / BUG-02 已在测试侧修正并验证；BUG-03 / BUG-04 的动画同步、BUG-05 的并行测试稳定性仍按原记录保留。
- 真实音乐副本、物理声卡、真实 DPI 与原生全局快捷键仍需补充实机验收。专项性能分析与优化尚未开始。
- 本轮不调用真实 AI、在线歌词或浏览器翻译服务；本地 Mock 通过不代表真实服务已验证可用。
