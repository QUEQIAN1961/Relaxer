# V0.2.1 外观编辑与模糊修复

基于 LauncherFix `2fe049f7c1dd7cd288116f0f7fe125367cbfdf94` 的独立分支。

- 文字、进度条、底栏颜色始终可见；未勾选时保留当前有效颜色的灰化预览并禁止点击，勾选后可编辑。图片与调色盘使用相同的同行排列。
- 图片共享与小字加粗按“左右同一张、底栏与页面共用、右侧小字加粗”同排。
- 四区模糊按左上列表、右上列表、左下底栏、右下展开播放排列，范围 0–50，精度 0.1。
- 展开播放封面路径原先固定模糊 50，现使用已保存的 blurExpanded；自定义图片背景继续使用同一参数。图像缓存键包含强度。
- 新增独立 blurFooter；旧外观没有此键时沿用 blurRight，保存后独立保留。只增加外观 JSON 属性，不修改 SQLite schema。
- 编辑页工具栏对齐普通页面的垂直起点和 36 高度；三个窗口按钮统一 42×32、矢量绘制图标，最大化后显示还原图标。原关闭保护保留。

仅构建受影响程序目标与专用 appearance-controls 验证程序。专用用例覆盖两种窗口尺寸、灰化禁用/启用、同排/2×2、旧记录兼容、独立保存、模糊像素变化及窗口操作。
没有运行全量 CTest/QtTest、47 项矩阵、ManualUX13/ExitGuardFix/WASAPI 全量复验。
打包使用匹配二进制和源码身份的定向原生证明，交付标记明确为 scoped development verification，不伪称本轮重做音频或 Harness 验收。
版本仍为 0.2.1；没有 Tag、Push、Merge 或 Release。新候选待用户及 Harness 专项验收，历史关闭记录不变。
