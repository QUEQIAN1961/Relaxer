# V0.2.1 手动体验修复变更清单

开发基线：`b5c66ebeea3319e4197ade08971afc06fb4825e1`，独立分支 `fix/v021-manual-ux-13`。版本号继续使用 V0.2.1；这是交给 Harness 独立验收的候选，不是发布版本。

截图依据及模块对应关系见 [截图映射](manual-ux13-screenshot-map.md)。15 张用户原图及哈希单独保存在交接包，历史工作树和旧验收材料保留。

| 反馈 | 最终行为 | 主要模块 |
| --- | --- | --- |
| 1 | 点击“使用选中版本”直接保存；普通歌曲不再逐首确认。只有该歌曲有运行中的翻译或未保存翻译预览才提示冲突。 | LyricsWorkspace |
| 2 | 进入待确认歌曲即选中排名最高的可见候选并预览；只看滚动歌词时选最高排名的滚动候选。刷新排名会更新自动推荐；已手动选择且仍存在的候选保留。 | LyricsSearchBridge |
| 3 | 保存成功后按当前列表顺序寻找下一首可见的 ⚠ 歌曲，循环查找并跳过已完成项，自动推荐、显示原文并滚入视野。失败留在当前歌曲；没有下一首时显示完成提示。当前播放和队列不变。 | LyricsWorkspace |
| 4 | 左栏“无歌词 / 无翻译 / 多选”压缩为单行勾选项；进入多选后第三项变“取消”，右侧出现“全选”，只选当前筛选下全部歌曲；取消清空多选。沿用原来的互斥筛选语义。 | LyricsWorkspace |
| 5 | “标记为纯音乐”从更多操作移至“使用选中版本”左侧；扣除间距后宽度占 35% / 65%。纯音乐确认成功也进入下一首待处理歌曲。 | LyricsWorkspace |
| 6 | 收紧页头、返回按钮及页脚的高度，三栏向上下扩展；窄高窗口继续使用紧凑控件。 | LyricsWorkspace |
| 7 | 手动滚动时高亮最靠近歌词视口中线的歌词，显示定位横线和时间播放按钮；定位播放、手动返回及空闲恢复跟随沿用原逻辑。 | LyricsList |
| 8 | 重复点击当前导航项/歌单直接返回，不重新播放页面切换动画；展开播放页时只收起播放页。 | Main |
| 9 | 未保存外观弹窗的取消、放弃修改、保存统一高度、间距和右对齐内边距。 | AppearancePage |
| 10 | 保存并退出、新建并保存、覆盖并保存、恢复默认配色按模式放入标题栏右侧。 | AppearancePage |
| 11 | 恢复完整非原生 QWidget QColorDialog：基本色、自定义色、屏幕取色、HSV、RGB、HTML 色值。接受后修改草稿，取消无修改；外观会话结束后旧选色结果失效。 | SettingsBridge |
| 12 | 按旧版恢复横向均分模式、底色与文字三列色块、进度颜色、底栏颜色、文字加粗、图片路径与共用选项、三列模糊滑块和小数输入。色块直接显示当前选色并自动选择对比文字。 | AppearancePage / ColorSwatch |
| 13 | 页面和共用底栏按整窗尺寸及偏移裁剪同一背景画布，避免底栏独立重缩放。左右分图时右图与底栏共享画布，左侧独立，沿用旧版行为；关闭共用后恢复独立底栏背景。 | Main / PlayerBar |

保留候选身份、目标歌曲、候选修订及本地歌词快照校验；只有成功保存后才丢弃已明确确认冲突的翻译状态，避免保存失败同时丢失预览。

验证采用专用 `relaxer_manual_ux13_tests`，覆盖上述主要交互及失败保护。测试使用临时歌曲和本地假翻译服务，不接触真实歌曲或 AI 凭据。构建、定向测试、截图及候选原生启动结果以交接包 `evidence` 和 `HANDOFF.md` 为准。未进行全量 CTest/QtTest、47 启动矩阵、重复稳定性或 WASAPI 测试。
