# Phase G：分P与失效媒体（2026-11-13）

## 已确认

- 底栏上一首/下一首切换队列中的视频或歌曲，分P操作独立。
- 当前P自然结束续播下一P，最后一P结束后进入队列下一项；队列仍一个视频一项。
- 切P沿用画质上限、音质、音量和播放/暂停意图，记忆各P进度；自动续P从头播放。
- 宽窗顶行为“收起、16:9封面、标题、作者、最右选集”；仅窄窗选集入口在窗口四键左侧。按2026-11-14追加要求，展开播放的视频封面（含只音频模式）为16:9居中裁切；列表与下一首封面继续4:3，视频画面保持原比例。
- 单P选集入口保留、灰色禁用。多P可点列表、上一P/下一P，面板内高亮当前项、搜索并定位。
- 失效或不可播放的媒体沿共享队列自动跳过；网络临时失败先有限重试。全部后续项不可播放时停止，避免无限循环；顺序模式到队列末尾停止。
