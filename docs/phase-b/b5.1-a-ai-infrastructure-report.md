## 实现范围

- 新增不依赖 Qt Widgets 的 AI Provider 接口、Provider Registry、DeepSeek Provider、Model Registry 和请求协调器。
- DeepSeek Provider 使用官方 `https://api.deepseek.com/models` 与 `/chat/completions`；实现模型列表读取、JSON 请求、usage 解析、限额/认证/网络错误分类和取消。
- 思考关闭时明确发送 `thinking.type = disabled`；开启时只允许模型声明支持的 `low`、`high`、`max`，不发送虚假的 `medium`。
- 动态模型列表保留服务端新模型与能力元数据。仅 `deepseek-flash` 和 `deepseek-v4-pro` 有已确认的结构化请求协议；其他新模型可显示，但未确认 Chat Completions、JSON Output、`max_tokens` 和思考控制协议前不能进入实际任务。
- 模型刷新失败不会覆盖已保存的模型选择；成功列表中消失的旧模型会标记为不可用并保留配置，不自动替换。
- 新增 Windows Credential Manager `CredentialStore`，并提供可注入接口。凭据不写入 Library 设置、JSON 或 SQLite；AI 配置写入已有 Library 设置键 `aiServiceConfigV1`，没有修改数据库 schema。
- 设置页新增“AI 服务”二级页面及“歌词翻译”设置页，包含凭据管理、模型与思考配置、全局/功能覆盖、简体中文目标语言、可编辑风格提示和云端处理说明。新增页面使用 Qt Layout、QScrollArea 与动态表单布局。
- 网页翻译入口与歌词翻译界面仍保持原状；本里程碑只完成 AI 基础设施和设置页，没有提前实现 B5.1-B。
