# B5.1 整首翻译修复（2026-10-16）

基于 B5.1 R2 `5dd31383f5f9b15e6cf631873a81593b8e39715a`。本轮为开发测试修复，产品版本保持 1.10.0，不宣布 B5.1 正式结项。

## 行为变化

- 翻译完成后右下角仅显示“翻译完成”，左下角保留核对预览、计费和 token 详情。失败、取消、保存及保存失败同步更新短状态和进度，避免残留等待提示。
- 模型列表仍使用 Provider/协调器 30/31 秒；整首翻译改为 180/185 秒。共享类型化超时策略，按请求捕获预算；后续修改设置不影响已派发任务。300 秒上界给协调器预留余量。
- 明确区分内容过滤、输出截断、推理资源不足、服务端中断、意外工具调用、未知结束原因、空响应及非法协议。先读取 finish_reason/usage，过滤且 content=null 不再误报正文类型错误。
- 已知失败用量继续显示；未知用量不视为免费。安全 JSON 诊断仅发送到 Qt 日志通道，含任务、时间、预算、状态和可用计量，不含 Key、歌词、正文或推理内容；应用启动方式决定该通道是否写入文件。
- 固定提示词允许对个别不能翻译的行返回“（内容已屏蔽）”，仍严格要求完整 ID 和单行文本；预览提示占位行数，原文保持不变。固定提示也纳入配置摘要。

一次用户同意仍只发送一次整首请求。不自动拆分、重试、换模型，不静默改变思考配置。失败、过滤和迟到结果不允许写入歌词；只有用户点击保存才写入。现有凭据、官方端点、快照、取消和未保存预览护栏继续保留。

## 边界

本轮不引入本地词库预审或第二次云端审查，不承诺供应商整体拒绝时能返回其他行。普通身体词和隐喻不得因单词命中而屏蔽。占位提示不是完整国内合规认证。

不依据历史超时截图认定两首歌被审查。本地 mock 只证明程序行为；未调用真实翻译 API，不声明两曲实网翻译已通过。独立测试、完整回归、运行包验证和源码归档校验的实际结果见本轮 D:\Git\Relaxer Markdown 交接报告。
