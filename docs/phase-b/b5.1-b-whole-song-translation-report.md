## 实现

- 新增 `src/ai/whole-song-lyrics-translation.{h,cpp}`。它从整份歌词提取有效行，为每行分配本地 ID；系统结构提示与用户风格提示分开；合并时沿用本地原文、时间戳和顺序。重复时间戳使用行 ID 区分，已有双语、空白、纯音乐及无有效歌词会被拒绝。
- `LyricsLookup` 使用窗口注入的 `AiRuntime`，通过异步请求协调器对当前单曲发出一次 DeepSeek Chat Completions 请求。发送前明确说明云端处理、一次请求及潜在费用；不自动拆分、切换模型或重试。请求和预览绑定歌曲、歌词内容与 AI 配置快照。
- 响应必须为正常结束且完整的 JSON；校验根结构、数组长度、整数 ID、重复/未知/遗漏 ID、字段类型、非空单行文本和意外时间戳。推理内容不会进入译文。失败、截断、取消或过期结果不会进入可保存预览。
- 结果以原文和译文双栏展示；只有用户确认“保存双语歌词”后才写入。`Library::saveLyricsPreservingText()` 绕过原保存路径的繁简转换，使用原有歌词文件路径管理，并在写入/数据库提交失败时恢复原文件。取消保存保留旧歌词。
- 翻译请求可取消；切歌、开始歌词搜索、歌词或配置变化以及窗口关闭都会使旧结果失效。UI 会说明本地取消不一定能撤回供应商已收到的请求。
- 移除了网页翻译按钮、自动翻译复选框、网页翻译供应商配置控件及用户流程调用。`BrowserTranslation`/CDP 服务和相关底层保护仍保留在独立服务目标与隔离测试中，不再由正常歌词查找流程启动。历史双语歌词及播放器读取流程未删除。

## 专项验证

所有 API 测试使用本地 HTTP Mock、假凭据和临时 Library，没有真实 DeepSeek 请求，也没有产生付费请求。整首翻译专项覆盖重复时间戳、双语识别、空歌词/纯音乐、严格 ID 校验、乱序映射、云端同意、单请求预览、用户保存、401 脱敏且不重试、非法 JSON 后手动重试、长度截断、上下文上限、歌词快照变化、切歌取消、窗口关闭取消、Windows 文件替换失败后保留并重试保存。

最终 Windows Release 全量验收中，`relaxer_ai_lyrics_translation` 为 15/15 通过；Phase031 为 33/33 通过。整套工程为 39/39 CTest 通过；QtTest 汇总 603 通过、0 失败、4 跳过。详细跳过项与旧网页翻译测试迁移关系见最终 Windows 测试报告。

真实 DeepSeek 在线连接、费用账单表现和实际翻译质量仍待用户在 Relaxer 中自行配置凭据并验收。Mock 结果不代表真实 API 实测。
