# Relaxer 0.2.0-GA

Windows x64 本地音乐播放器，使用 Widgets 界面。

下载完整便携版并解压，运行 RelaxerStart.exe。版本说明见 [RELEASE-NOTES-V0.2.0-GA.md](RELEASE-NOTES-V0.2.0-GA.md)。
当前其他版本及中英文指南见 [GitHub 仓库](https://github.com/QUEQIAN1961/Relaxer)。

源码构建需 MSYS2 UCRT64、CMake、Ninja 和 Qt 6。配置后构建 Relaxer 与 RelaxerStart 目标。使用 CMAKE_PREFIX_PATH 指向对应 Qt 前缀。
