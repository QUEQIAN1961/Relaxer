# Relaxer V0.2.0-rc1 · Phase B 发布候选版

本版使用 Windows MSYS2 UCRT64 构建。当前为 Release Candidate，等待 Harness R9 独立验收和用户正式发布确认。版本命名由历史 1.10.0 调整为 0.2.0，应用名称、资料目录与数据库格式保持兼容；不会因版本号变化清空旧数据。

新增内容及已知限制见 `V0.2.0-ReleaseNotes.md` 与 `V0.2.0-Known-Issues.md`。便携发行包包含已构建的 runtime；本源码包保留既有首次准备启动方式。

解压后双击 `RelaxerStart.exe`。包内提供源码、资源、原生启动器和环境检查组件；播放器主程序在本机首次启动时编译。首次准备会优先复用已有 MSYS2 UCRT64，检查依赖、构建并验证运行文件；没有已有环境时联网准备。日常本地播放可离线使用。

从旧版升级：

1. 完全退出播放器，包括托盘中的实例。
2. 完整解压 ZIP 到新目录。
3. 将旧目录整个 `data` 文件夹复制到新目录，与 `RelaxerStart.exe` 同级。
4. 如有自定义环境路径，可复制 `msys2-path.txt`。
5. 双击新目录的启动器，首次准备完成后进入 V0.2.0-rc1。

歌曲、歌单、收藏、歌词、统计和设置会继续使用。音乐仍复制到 `data/Music`，原始文件保留。`start-Relaxer.cmd` 和 `创建桌面快捷方式.vbs` 均使用同一启动入口。

V1.7 更新：

- **歌词显示与微调**：大屏歌词支持长句自动换行、同时间原文与译文成组、平滑切换及手动滚动。滚动时只显示中间句时间，3 秒后返回播放句；底部可逐首保存 ±1.00 秒、0.01 秒精度的额外歌词偏移。设置可选择歌词颜色、大屏是否使用封面背景；背景模糊沿用已有设置。
- **在线歌词**：同时处理 3～5 首歌曲，每首同时安排 3～5 个查询，按响应与异常调节并发。保留原来的查询阶梯与两个来源，补充专辑、CJK 标题去空格和手动歌词片段；仅精确查询发送歌曲时长。用歌曲身份与取消代次隔离响应。
- **手动搜索与缓存**：候选保存 30 天，来源确实回答而无结果保存 7 天；手动搜索及替换绕过缓存，超时、网络错误、查询不完整不写无结果缓存。保存过的同曲歌词可复用，已知歌手且时长相近时才静默复制；同名同歌手仍可能存在版本误配，可重新检索替换。
- **人工补充**：来源和滚动歌词筛选保留正确的版本映射，推荐理由显示在候选标题与提示。更多操作包含片段、粘贴、导入、纯音乐标记、±5000 ms 文件偏移。文件偏移与播放页微调分别保存；文件偏移为 0 时保留原内容，非零为绝对文件偏移。
- **来源与异常**：继续使用 LRCLIB 与 Lyrics.ovh，备用只提供手动候选并清理实体和换行。5xx 对同一查询只额外重试一次，限流和超时不重试。自动保存前检查有效行数、时间范围及网页内容，短歌词可能从自动保存变为需选择。
- **纯音乐**：明确匹配且无冲突时保存纯音乐标记；疑似情况留给用户确认，没搜到歌词不等于纯音乐。确认后显示“纯音乐，请欣赏”，这段文字不接受点击跳转，没有滚动时间提示与歌词微调；正常进度条仍可拖动。
- **下一首与大屏**：普通界面在音量条下显示单行下一首，展开无封面；大屏左下收起显示标题加两首，展开最多总计六行（标题一行、歌曲五行）。更多歌曲内部滚动，歌名和歌手分别限制为 6、4 个汉字的显示宽度，省略号计入上限。随机预览与随后实际切歌一致。进入大屏隐藏侧栏并衔接两侧队列，点击大屏队列可触发封面与文字飞入，底部上下首及自动切歌不触发。
- **毛玻璃与性能**：圆角队列模糊背后的画面，使用已有曲线的 25% 强度。切歌、背景或尺寸变化才更新缓存，绘制与动画不重新计算高斯模糊；歌词布局在内容或宽度变化时计算并复用。

- **来源与异常**：主来源 LRCLIB，备用 Lyrics.ovh。备用来源缺少可靠版本和时长信息，候选仅供手动确认。区分超时、网络异常、服务错误、无结果与候选不匹配；每次请求及单曲整体检索均有时限，采用异步请求。
- **版本日志**：统一 V1.4、V1.5 与此前版本的标题、日期和段落格式。
- **悬浮提示与背景**：移除序号、时间、大小、日期和完整可见文字的多余提示；保留省略文字、图标功能和必要错误说明。表头、设置外层及版本日志去除大块底框，按钮、输入框和设置卡片保留原风格。
- **歌单顶部**：滚动时封面平滑缩到左上方；两行操作与右侧信息对应，简介收起后单行省略并避开按钮列，第二行按钮统一圆角样式。
- **列宽**：拖动歌曲表格文字列边界可调整宽度，跨页面和重启记忆；序号、收藏固定。
- **个人页与切换**：最近播放、最长播放高亮随当前选项变化。普通页面切换时自定义背景静止，进入或退出歌词页保留封面过渡。
- **模糊调节**：0–50%，支持一位小数及 0.1% 步进；采用低值缓慢、高值加快的指数曲线。旧设置数值保留并使用新曲线。歌手、专辑筛选弹窗继续使用原固定 25% 模糊。

公开接口文档：[LRCLIB](https://lrclib.net/docs)、[Lyrics.ovh](https://github.com/NTag/lyrics.ovh)。没有接入未经验证的网易云或 QQ 私有接口。实际结果受歌曲版本、数据库收录和网络状态影响，详见本包验证报告。

开发构建：C++17、Qt 6.4+、CMake、Ninja，Qt Core/Gui/Widgets/Sql/Multimedia/Svg/Test/Network。Windows 推荐 MSYS2 UCRT64；已有环境可在 UCRT64 终端执行 `bash scripts/build-windows-ucrt64.sh`。自定义路径可写入 `msys2-path.txt`，或设置 `RELAXER_MSYS2_DIR`。相关测试为 `relaxer_v16` 与 `relaxer_v19`。

首次准备的自动回归在无界面测试模式下执行，使用 `RELAXER_SKIP_AUDIO_DEVICE_TESTS=1` 跳过依赖实际声卡的音频输出用例（其余测试照常执行）。真实声卡播放测试需在具有音频设备的正常 Windows 会话中单独运行：手动调用 `relaxer_tests.exe realPlaybackAndSeek realResumeAndLoop` 并取消该环境变量。此设置不影响正常启动的播放器音频输出。实网歌词对比需单独设置 `RELAXER_LIVE_QA=1` 后执行 `relaxer_v16_tests liveSongComparison`；报告路径用 `RELAXER_BENCHMARK_FILE` 指定。

交付包不包含播放器主 EXE、运行库、runtime、构建缓存或个人 data。转发请使用本 ZIP。

歌词翻译已改为可选择必应或百度的本地浏览器翻译，默认必应；遇到网页验证时手动处理后点击“验证完成，继续”。需要本机已有 Edge 或 Chrome。使用独立浏览器配置，详情见 [浏览器翻译修复说明-2026-10-15.md](浏览器翻译修复说明-2026-10-15.md)。

## V1.6 启动修复说明（不升级版本号）

- 无界面回归期间不提前初始化系统声卡，减少声卡驱动引起的超时；真实声卡测试须单独进行。
- 页面返回时保留动画，增加异常延迟兜底恢复；测试等待动画状态而非依赖固定毫秒数。
- 自动测试报告同步输出到 CTest 控制台，便于定位卡住的测试；原 `Testing/QtResults` 报告仍保留。
- 仅在首次启动遇到 CMake 写入权限异常时，尝试在 Relaxer 专有缓存中创建隔离构建目录；不会清理已有 MSYS2。
