# Playlist markers

The 16 marker drawings are adapted from [Lucide 0.468.0](https://github.com/lucide-icons/lucide/tree/0.468.0/icons).
Their view box and stroke weight are adjusted to Relaxer's existing navigation icons;
the image provider supplies the current theme and selection colors.

The full upstream ISC notice and the MIT notice for Feather-derived drawings are
preserved in LICENSE.txt and embedded in the QML resources.
