# Playlist markers

The 48 current marker drawings are original Relaxer vectors, covered by the
project license. They share a 24-unit grid, 1.4-unit strokes, rounded caps and
joins. Existing marker identifiers are preserved for saved playlists. The image
provider supplies the current theme and selection colors.

LICENSE.txt retains the notices for the earlier Lucide/Feather-derived versions
for historical attribution; the current drawings were independently redrawn.
